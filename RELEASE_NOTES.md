**Session Deck** — every Claude Code conversation on your PC, one click away. Unofficial companion app for Claude Code on Windows.

### Install
1. Download **`SessionDeck-Setup-<version>.exe`** below and run it. No admin rights needed — it installs just for you.
2. Windows may show *"Windows protected your PC"* because the app isn't code-signed yet: click **More info → Run anyway**.
3. Open **Session Deck** from the Start Menu. There's no account or login — it reads the Claude Code data already on your PC.

Prefer no installer? Download the **portable zip**, extract it anywhere and run `SessionDeck.exe`.

**Needs:** Windows 10 or 11 and Claude Code (the `claude` CLI and/or the Claude desktop app's Code tab). Microsoft Edge (built into Windows) shows the window.

Want to look around first? Start Menu → **Session Deck (demo with sample sessions)**.

See [CHANGELOG.md](https://github.com/optimus-ook-prime-gluk/session-deck/blob/main/CHANGELOG.md) for what's new. `SHA256SUMS.txt` lets you verify the downloads.
